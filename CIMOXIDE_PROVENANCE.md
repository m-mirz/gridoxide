# cimoxide git dependency

`Cargo.toml`'s optional `cgmes` feature (`src/cgmes.rs`) depends on
[cimoxide](https://github.com/m-mirz/cimoxide)'s `cimdecoder`/`cimstructs`
crates — a separate Rust project by the same author providing CGMES
(Common Grid Model Exchange Standard) RDF/XML decoding into typed CIM
structs.

- **Upstream**: https://github.com/m-mirz/cimoxide
- **Branch**: `vendor/gridoxide`
- **Tag**: `v0.1.1-gridoxide.1`
- **Commit**: `44126a137365b2b17f00270068fc6f25e63eaf17`

## Why a git dependency, not crates.io

Neither `cimdecoder` nor `cimstructs` is published to crates.io (confirmed:
the sparse index returns `NoSuchKey` for both). Their source is also
generated by cimoxide's own code generator (`cargo run -p cimgen`, reading
ENTSO-E's RDF/SHACL schemas) and gitignored on cimoxide's `main` branch —
so a plain git dependency pinned to `main` wouldn't build either.

`vendor/gridoxide` exists specifically to work around this: it's `main` plus
one commit with `cimstructs/src/*.rs` and `cimvalidation/src/generated_*.rs`
force-added (overriding the `.gitignore` rule for that one commit), so a git
dependency pinned to this branch/tag resolves and builds standalone from a
fresh clone. cimoxide's own README documents this same branch on its side.

## Updating

To pick up a newer cimoxide schema or generator change:

1. In the cimoxide repo, branch again from `main` (a fresh `vendor/gridoxide`
   branch, or reuse the existing one), run `make generate`, verify
   `make build && make test` pass, then force-add and commit the generated
   `cimstructs`/`cimvalidation` files (matching the `.gitignore` override
   already documented on that branch) and cut a new tag.
2. Bump the `tag =` value in this repo's `Cargo.toml` for the `cimdecoder`
   and `cimstructs` dependencies to the new tag, and update the tag/commit
   noted above.
3. `cargo build --features cgmes` and `cargo test --features cgmes` to
   confirm the new rev still resolves and the converter still matches
   `tests/cgmes_microgrid_be_test.rs`'s expectations — CGMES field names or
   shapes could in principle change between schema versions.
